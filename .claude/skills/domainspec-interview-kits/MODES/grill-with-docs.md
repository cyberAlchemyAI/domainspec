# Mode: grill-with-docs

## Intent

Challenge assumptions and close blocker ambiguity before implementation/mutation.

## Question Formation Rules

1. Start from evidence-backed mismatches, not generic brainstorming.
2. Prefer questions that choose between concrete options.
3. Include one recommended default answer.
4. Include one unresolved-risk statement.
5. Include explicit patch target.

## Required Question Card Fields

- question
- why-now
- evidence-links
- recommended-answer
- unresolved-risk
- patch-target

## Cadence

- Ask one question.
- Wait for answer.
- Patch docs.
- Record decision snapshot.
- Continue.

## Stop Rules

- Stop on pass: no blocker ambiguity.
- Stop on block: operator declines core decision.
- Stop on flag: only non-blocker ambiguity remains.
