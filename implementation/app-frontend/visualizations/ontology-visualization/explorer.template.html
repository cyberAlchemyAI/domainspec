Welcome to the Ontology Explorer, a visual tool designed to help you navigate, understand, and analyze the knowledge graph of this vault.

How to Navigate

  • Left-Click: Select a node to focus it, load relationships, and read a brief summary.
  • Right-Click: Clear selection and reset view.
  • Pan & Zoom: Drag the background to pan (WASD in 3D). Use mouse wheel to zoom.

Visual Dimensions

  • Color By: Highlights node types (e.g., axioms are foundational, specs are behavioral, conceptuals are context).
  • Shelves (3D): Groups nodes onto distinct Z-axis layers (like Status or Architecture Layer) to easily distinguish hierarchies.
  • Size (Mass): Node size determines gravitational pull. Heavier nodes act as anchors with more connections and higher PageRank.

Links & Gravity

  • Links represent relationships (derives-from, implements, validates, refines, contextualizes, and more).
  • Gravity: Heavily cited documents (high in-degree) pull surrounding documents into orbit. Link particles flow towards the attractor.
