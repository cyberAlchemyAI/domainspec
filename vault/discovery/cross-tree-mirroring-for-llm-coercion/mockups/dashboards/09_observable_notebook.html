The state of structure: a 30-day reading

By Robot @ DomainSpec · Published 2026-05-18 · Maestro-trama

This notebook is the operational backstory of the discovery filed today. The proposal is that an LLM agent editing code at any path should be able to compute, not search, the path of its governing spec. The data below is the case that the current structure does not afford this — and the report card for the proposal's pilot.

We begin with the headline numbers, then the breakdown by feature, the promotion queue, and finally the trend over the last 30 days that explains the urgency.

The most consequential row is the first one. extraction/ exists at both docs/proposals/ad-creative-dna/features/extraction/ and apps/labeling-platform/features/extraction/, with separate SPEC.md files. They were created in a single commit on May 16 with no arbitration mechanism. Content has begun to drift.

The migration that produced the asymmetry was a half-migration: docs/features/ renamed to docs/proposals/ on the L₁ side, but the L₂ side's references to the old prefix were not rewritten. Every patch since has added more references. None of them break the build. The structure of the repository does not catch the divergence.

The agent was not careless. It had no computable path from its edit site to the spec that should have governed it, so it guessed, and the structure did not catch the guess.

Six of seven have earned identity (a known app and feature). One — the manifesto fragment — has not, and lives in the awkward middle: stable enough to deserve survival, unstructured enough to resist filing. The proposal's _unknown/ staging slot is the candidate landing zone.

What this notebook reports, and what it does not

This is a state reading, not a verdict. The proposal's coercion claim — that structural symmetry forces correctness — is parked behind a measurement plan that does not yet exist. Today's data demonstrates the cost of the missing structure; it does not yet demonstrate that the proposed structure lowers that cost. The follow-on notebook (OQ-1) is where that question lives.
