# Findings — o meio-termo entre meta-layers e two-layer-framework para a camada executiva

Dispatch: `2026-06-12-meio-termo-meta-layers-two-layer`. Returns: `research.md` (este folder). Síntese pelo parent (final_approver).

## A tensão real entre os dois polos

Os dois returns desenham a mesma disputa de ambos os lados (Dissent de Shannon ↔ Dissent de Simon):

- **meta-layers** entrega um **mapa vertical** — situa o leitor ANTES de qualquer afirmação (atribuição de camada, separação de trilhas, inventário de loops). Força: localiza onde o problema/drift entra. Fraqueza confessa: vocabulário de camadas é opaco sem legenda; denso demais para entrada (return Shannon §4).
- **two-layer** entrega uma **declaração tipada de status** — a entrada não é resumo, é a lista do que foi decidido com status epistêmico por item, sem preâmbulo. Força: impossível confundir decidido com assumido; honesto por construção. Fraqueza apontada pelo rival: tabela de status sem mapa fica desancorada (return Simon, Dissent).

## O meio-termo (decisão desta síntese)

A camada executiva adota **a espinha do two-layer com uma âncora mínima do meta-layers**:

1. **Abertura direta, sem preâmbulo** (two-layer §3-A): a(s) pergunta(s) que o documento responde, 1–2 frases.
2. **Uma linha de mapa, não um mapa** (concessão mínima ao meta-layers): uma única frase nomeando o pipeline/lugar onde o leitor está — o suficiente para ancorar os status sem importar vocabulário de camadas. Sem numeração de camadas (a supressão que o two-layer defende), MAS com a localização que o meta-layers exige.
3. **Bullets tipados por status** (two-layer §3-B, fundido com o desenho do review de legibilidade 2026-06-12): ≤8 bullets, cada um *problema → escolha → porquê*, com tag de status em vocabulário comum — [DECIDIDO] / [DECIDIDO, PENDE EMENDA] / [ABERTO] / [MORTO] — **declarada como tradução informal** do vocabulário canônico (GO / GO-condicional / OPEN / KILL), e cada bullet apontando para a seção dona (âncora obrigatória; bullet nunca decide).
4. **Falsificação em uma linha** (collapse test do meta-layers ≡ condição-de-fechamento do two-layer — os dois modelos convergem aqui): o que provaria o desenho errado.
5. **Quem decide o quê, em uma linha** (a parede honesta do two-layer §3-E + a separação de trilhas do meta-layers): este doc nomeia; os vereditos moram em outro lugar, nomeado.

O que a camada executiva NÃO contém (two-layer, adotado integral): motivação histórica, derivações, notas de implementação, reimpressão de cadeias causais.

## Por que este corte

- A falha que o owner reportou é de **entrada** (ninguém de fora consegue começar), não de falta de mapa — então a espinha é do two-layer (status direto), não do meta-layers (mapa primeiro). 
- Mas a crítica do meta-layers é verificada na prática: status sem ancoragem não orienta — daí a linha única de mapa (item 2) e a âncora por bullet (item 3).
- O vocabulário de status em linguagem comum com flag de tradução informal satisfaz simultaneamente o status-typing do two-layer e a disciplina "glosa ≠ definição" do review de legibilidade (findings 2026-06-12-views-skills-legibility-review, CR-3/CR-7).
