# AGT-02 - Interviewer Flow for Greenfield Mapping

## Objective

Provide an interviewer flow that helps users define business problems, pain points, value targets, and initial domain map for new systems.

## Problem

Greenfield users struggle to transform broad ideas into implementation-ready domain structures.

## Scope

- In scope:
  - Guided interview stages for goals, constraints, and domain boundaries.
  - Output artifacts usable by planning and specification steps.
  - Value and pain-point capture tied to objective model.
- Out of scope:
  - Brownfield auditing.

## Dependencies

- [AGT-01-orchestrator-interface.md](AGT-01-orchestrator-interface.md)
- [../context/CTX-01-context-objective-prioritization.md](../context/CTX-01-context-objective-prioritization.md)

## Implementation Tasks

1. Define interview stages and minimum required answers.
2. Add adaptive follow-up questions based on ambiguity risk.
3. Add mapping output format for domain concepts and workflows.
4. Add pain-point and value traceability fields.
5. Add handoff package for spec and planning skills.

## Deliverables

- Greenfield interview flow.
- Adaptive question policy.
- Output artifact schema.
- Handoff package format.

## Done Criteria

- [ ] Interview output is directly consumable by implementation planning.
- [ ] Pain points and value goals are explicit and measurable.
- [ ] Missing critical context is flagged before handoff.
