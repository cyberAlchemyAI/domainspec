# Capability Sequence Lessons

## Purpose

Capture implementation lessons from Capability 1 so subsequent capability task packs can reuse proven sequencing constraints.

## Entry Template

| Field      | Description                                                 |
| ---------- | ----------------------------------------------------------- | -------------- | ------ | ---------- |
| Capability | Capability identifier (for example `CAP-AEO-C1`)            |
| Task       | Task ID that produced the lesson                            |
| Type       | `pattern`                                                   | `anti-pattern` | `risk` | `decision` |
| Lesson     | Short statement of what changed execution quality           |
| Evidence   | Link to artifact, verification command, or report           |
| Reuse Rule | How to apply this lesson when designing Capability 2+ tasks |
