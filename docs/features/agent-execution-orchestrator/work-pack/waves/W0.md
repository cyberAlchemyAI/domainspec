## Architecture Constraints Baseline

1. Pipeline routes must be explicit and composable (no dynamic-router-only baseline).
2. Run lifecycle semantics must align with Sandcastle-style execution model (`createSandbox`, worktree lease, lifecycle hooks, terminal outcomes).
3. Domain/application lifecycle contracts stay provider-agnostic; provider-specific logic remains in adapters.
4. Branch strategy default is `merge-to-head` and must be represented as an explicit policy artifact.
5. Superseded run behavior uses `latest-run-wins` cancellation semantics.
6. Standard evidence envelope must include delegated stage terminal outcomes, terminal-guard evidence, and decision snapshot context.
