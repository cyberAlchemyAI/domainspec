# Refine Result: Optimization Chain Definitions

## Final Synthesis

GoldenQuill needs an `OptimizationChainDefinition` artifact. It is neither a
raw statistic nor an approved lesson. It is the governed sentence contract that
turns an action/KPI association into a named BI optimization with claim limits,
privacy scope, and a route to owner decision.

## Required Expression Forms

| Form | Purpose |
| --- | --- |
| `plain_language` | Lets non-technical users understand the learning loop. |
| `operator` | Tells implementation and workflow owners what is measured. |
| `executive` | States the competitive advantage without overclaiming. |
| `contract` | Carries the minimal schema-ready definition. |
| `causal_careful` | Prevents descriptive evidence from sounding causal. |
| `dashboard_label` | Provides BI naming without hiding uncertainty. |
| `ontology` | Makes graph projection explicit. |

## Placement Decision

`OptimizationChainDefinition` is created after
[ActionKpiAssociation](../../../analytics-methods.md#actionkpiassociation) and
before [BIInsightCandidate](../../../analytics-methods.md#biinsightcandidate-profile).
This keeps the BI explanation tied to evidence while preserving owner approval
as the only route to approved reuse.
